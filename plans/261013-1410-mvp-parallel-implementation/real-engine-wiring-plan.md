## Design decisions
A. Connector engine/real/connector.rs HttpConnector: one Arc<HttpTransport> (TransportConfig from settings, AuthBroker as AuthPrompter, AppDbTrustStore); session cache by repo root (longest prefix; host case-insensitive); on miss HttpRaSession::open(requested url) (path authz), store under repos_root(). SessionConnector::connect_with(url, &ConnectOptions{anchor: Root|Url, interactive}, cancel) default delegates to connect. Returns base.reparent(target) (+ .unattended() when !interactive). ensure_authenticated connects at WC URL. App feature negotiate-gssapi = ["svn-ra/negotiate-gssapi"] (on for macOS/Linux release, off default CI); settings switch to disable. Rebuild transport/clear cache on settings change/sign-out.
B. Auth: AuthPrompter::stored_credentials(&CredentialRequest)->Option<Credentials> default None, called in both modes before credentials(); AuthBroker implements via AccountRecord + secure-store; replace NoSecretStore. auth/trust.rs AppDbTrustStore: pinned() from in-memory map (TLS handshake must not block), pin/replace_pins update map.
C. AppDeps.engine -> enum EngineSource { Ready(Arc<dyn EngineFacade>), Build(Box<dyn FnOnce(EngineServices)->Result<..>>) }, EngineServices{auth, db, data_dir, settings}; build broker first.
D. Progress: engine/real/progress.rs client_progress(&ProgressReporter)->svn_client::ProgressFn; UpdateEvent -> ProgressUpdate{phase:"update", current, current_path}; ctx.cancel passed as &CancelToken; commit phases collect/upload/merge/finalize.
E. Locks: no new app lock; WcActor serializes in-process; svn-wc WC_LOCK via svn-client with ClientCtx{lock_owner: self.lock_owner()}; sync local ops in wc_read::blocking with svn_client::wc::open_containing.
F. Journals: svn-client journal is the single source of truth; port app journal safety rules (unknown version untouched, corrupt quarantined no-replace, unreadable kept) into it; delete engine/real/journal.rs and RecoveryHooks::finalize_commit; store in <state_dir>/commit-journals/.
G. Mapping engine/real/wc_map.rs: WcStatus->FileStatus (lock.mine, no token exposed), ResolveChoice Mine->MineFull, Theirs->TheirsFull, Working, Base with ResolveScope::ALL; errors via AppError::from(&SvnError).
